# 忘却曲線カレンダー / Forgetting Curve Calendar

**そのメモ、もちろん忘れます**

その日書いたメモを、忘却曲線に沿って自動でリマインドするカレンダー型メモ帳です。
スマホ・PC 両対応。インストール不要のブラウザアプリ（データは端末内に保存されます）。

👉 **[アプリを開く](https://masakiniwa.github.io/Forgetting-Curve-Calendar/)**

---

## できること

- ✍️ **全画面のテキストエディタ** — タイトル・手掛かり・本文が 1 枚の紙。境界線なしで一緒にスクロール
- ◎ **手掛かりが最初から見える** — 復習で最初に出る「問い」を、書くときに必ず目にする位置へ
- 🔖 **見出しとアウトライン** — 行頭の `# ` で見出し。`Ctrl/⌘+K` でその場所へ移動
- ↩️ **元に戻す / やり直す・検索置換** — 一括置換も 1 回で戻せる。日本語入力にも配慮
- 💾 **自動保存** — 保存状態が常に見える。失敗したら画面に留まり、再試行と本文のコピーができる
- ✅ **箇条書きの続き** — Enter で次の記号を補い、空の項目で終わる。空行でボタンを押せばすぐ書ける
- 📝 **メモを書くと復習日が自動で並ぶ** — 1 日後、3 日後、7 日後… と、数年先まで未来の日付に配置
- 🧠 **「読む」ではなく「思い出す」** — 復習では手掛かりだけが出る。思い出してから内容を開いて答え合わせ
- ▶️ **集中復習モード** — 今日の分をまとめて 1 件ずつ。終わると「また忘れる頃に会いましょう」
- 📅 **カレンダーで記憶の地図が見える** — その日に積み上がった過去のメモを確認。年月ピッカーで数十年先へも移動
- ♻️ **想起結果で賢く再スケジュール** — 「覚えていた / あいまい / 忘れた」に応じて残りの復習日を自動調整
- ↩️ **正確な取り消し** — 記録は出来事として保存。取り消すと定着度も未来の予定も元どおり
- 🌱 **追加メモからも曲線が発生** — 過去メモに紐付けた気づきが、それ自身の忘却曲線を持つ
- 🎲 **復習日が散らばる** — 同じ日に書いても、メモごとのシードで先の予定ほど前後にずれる
- 📊 **記録画面** — 連続日数、想起の内訳、16 週間のヒートマップ、これから 12 ヶ月の予定
- 🌳 **記憶の枝** — メモから生まれた気づきのつながりをたどれる
- 📴 **オフライン対応** — 一度開けば圏外でも起動。ホーム画面にも追加できる
- 🕊️ **たまっても大丈夫** — やり残しは「思い出し待ち」として、1 日 N 件ずつ。終えたら補充されない
- 🗂️ **あとで決める** — 復習の予定を付けずに保存し、あとから始めることもできる
- 🏁 **節目が残る** — 最初の再会、初めての気づき、7日続けて触れた… を「記録」画面に
- 📆 **活動した日は消えない** — 日ごとに記録するので、あとから書き足しても過去の活動日が減らない
- 🔎 **検索と絞り込みは上に固定** — 長い一覧をスクロールしても操作を見失わない
- ⚡ **たくさんのメモでも軽い** — 2000 件で起動 0.8 秒・一覧 0.08 秒（保存はまとめて 1 回）
- 🔒 **書けるタブは 1 つだけ** — 同時に書いて片方の変更が消えることがない。譲り受けはボタン 1 つ
- ◎ **デイリーミッション** — 毎日 4 つまでの小さなお題。1 つでも達成すればその日は「続いた日」
- 🎴 **今日のやる気くじ** — 全部そろえた日に 1 回。120 種類の占いから 1 つ（凶はありません）
- 🛡️ **おまもり** — 7 日続けるごとに 1 つ。できなかった日を肩代わりするので、途切れにくい
- 📤 **テキスト出力** — Markdown / テキスト / CSV / JSON でエクスポート
- 💾 **完全バックアップと復元** — 全データを JSON で保存・復元。画面右上からいつでも保存でき、最後に保存してからの日数も出ます
- ⚙️ **設定 / ヘルプ** — 曲線プリセット、テーマ、週の開始曜日ほか

## 使い方

1. 右下の **+** ボタンでメモを書く（任意で「思い出すための手掛かり」も書ける）
2. カレンダーの未来日に、数年先まで復習が自動配置される
3. 上部の「今日の記憶」から **［思い出し始める］**
4. 手掛かりを見て思い出し、**［内容を見る］** で答え合わせ
5. 「覚えていた / あいまい / 忘れた」を記録すると、残りの復習日が自動で調整される

詳しくはアプリ内の **ヘルプ** ページを参照してください。

## 忘却曲線のプリセット

| プリセット | 回数 | 最長 |
| --- | --- | --- |
| 標準 | 11 回 | 約 5 年 |
| 集中 | 13 回 | 約 4 年 |
| ゆるめ | 9 回 | 約 8 年 |
| 一生もの | 12 回 | 約 30 年 |
| カスタム | 任意 | 最大 100 年 |

遠い先ほど間隔が大きく開くので、年単位まで伸ばしても回数はほとんど増えません。
同じ日に書いたメモでも、遠い予定ほど自動的に散らばります（分散の強さは設定で変更可）。

## 技術構成

- 依存ライブラリなしの **静的サイト**（ES Modules / CSS Custom Properties）
- Material Design 3 を参考にしたカラートークンとコンポーネント
- データは `IndexedDB` にメモ 1 件ずつ（使えない環境では `localStorage` へ自動で切り替え）。
  復習の予定は保存せず、出来事から組み直す。
  ストレージ層を抽象化しており、将来の同期実装に差し替え可能

```
index.html
assets/
  css/    tokens.css / app.css
  js/
    core/  storage / migrations / models / curve / missions / store / exporter … ドメイン（UI 非依存）
    ui/    app / editor / missions / backup / reviewSession / components …
    editor/  history / textEditor … テキスト編集の中核（UI 非依存）
    ui/      … charts / reviewSession ほか
    ui/views/  calendar / noteEditor / notes / stats / settings / help
docs/SPEC.md    仕様書
tests/          コアロジックのテスト（node --test）
```

復習の予定は保存された結果ではなく、**「起点 + 出来事の並び」を再生して導出**しています
（`core/curve.js` の `replay`）。そのため取り消しが正確で、将来アルゴリズムを差し替えても
過去の記録を作り直す必要がありません。

設計の詳細・ロードマップは [docs/SPEC.md](docs/SPEC.md) を参照してください。

## ローカルで動かす

```bash
git clone https://github.com/MasakiNiwa/Forgetting-Curve-Calendar.git
cd Forgetting-Curve-Calendar
python3 -m http.server 8000
# http://localhost:8000 を開く
```

ES Modules を使っているため、`file://` で直接開かずローカルサーバ経由で開いてください。

コアロジックのテスト:

```bash
npm test
```

## デプロイ

`main` ブランチへの push で GitHub Actions がそのまま GitHub Pages へ公開します
